# Doc-Writer — Reference

## Rules
- Cite only from `source`. Empty source = refusal.
- No first person. No hedging unless source hedges.
- Match the tone of `agent-style.md`: terse, declarative.

## Bilingual
When `lang: ms`, route through the MS glossary before returning.
Both EN and MS must express the same claims — no MS-only details.

## Kinds
| Kind | Shape |
|---|---|
| memo | To / From / Date / Re + I–V sections |
| summary | ≤3 sentences, one idea each |
| readme | H1 title, layout table, usage code fence |
| commit | imperative subject ≤72 chars, body optional |
| changelog | Reverse-chronological, grouped by kind |
