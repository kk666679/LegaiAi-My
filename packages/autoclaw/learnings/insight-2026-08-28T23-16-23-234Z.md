# Insight: cite-check before conclusion

**Observed.** In two of five IRAC runs, the conclusion section cited
authorities that were never retrieved. Consensus still accepted
because the validators only checked logic shape, not source existence.

**Root cause.** `validate.citation` was optional in the pipeline and
skipped when the rule node returned zero items.

**Fix.** Make citation validation a hard precondition for the
`conclusion` node: if rules are empty, the pipeline must return
`{ status: "insufficient-authority" }` instead of drafting a conclusion.

**Impact.** Eliminates fabricated citations; adds one round-trip to
the critical path in the empty-rules case only.
