# ASEAN Legal Terminology & Citation Formats

Consolidated terminology and citation conventions for all ASEAN
jurisdictions. This file complements `legal-terminology.md`
(Malaysia-centric core terms) by covering the citation formats,
instrument types, and institution names used across the region.

**Purpose:** consistent terminology is critical for retrieval
accuracy and for preventing jurisdiction contamination. Preserve
original local-language terms as canonical; use English equivalents
as aliases.

## Citation formats by jurisdiction

| Jurisdiction | Principal legislation | Amendment | Subordinate / regulatory | Constitutional provision |
|--------------|--------------------|-----------|--------------------------|------------------------|
| MY | `Act NNN` (continuous) | `Act A`nnn | `P.U. (A) NNN`, `P.U. (B) NNN` | Federal Constitution, **Article** N |
| SG | `Act NNN of YYYY` / `Cap. NNN` (revised) | `Act NNN of YYYY` | `S` NNN / `G.N.` / `L.N.` | Constitution, **Article** N |
| ID | `UU No. X Tahun YYYY` | `UU No. X Tahun YYYY` (amending) | `PP`, `Perpres`, `Permen` | 1945 Constitution, **Pasal** N |
| PH | `Republic Act No. XXXX` | `Republic Act No. XXXX` | `Executive Order`, `Administrative Order`, `IRR` | 1987 Constitution, **Article** N, **Section** N |
| TH | `Public Act (P.A.)` / `Royal Decree (R.D.)` | `P.A.` / `R.D.` | Ministerial Regulations | Constitution, **Section** N |
| VN | `Law No. XX/YYYY-NQ` / `-CP` | `Law No. XX/YYYY` | `Decree (NĐ-CP)`, `Decision (QĐ-TTg)`, `Circular (TT-BTC)` | 2013 Constitution, **Article** N |
| KH | `NS/RKM/XXXX/YY` (royal decree) | — | Sub-decree, Prakas | Constitution, **Article** N |
| LA | `No. X/NA` (law) / `No. X/PM` (decree) | — | Ministerial ordinance | Constitution, **Article** N |
| MM | `Law No. X/YYYY` | `Law No. X/YYYY` | Rules, Notifications | 2008 Constitution, **Article** N |
| BN | `Chapter NNN` (Cap.) | — | `S.R.`, `P.U.` | Constitution, **Article** N |
| TL | `Law No. X/YYYY` | `Decree-Law No. X/YYYY` | `Decree`, `Ministerial Diploma` | 2002 Constitution, **Article** N |

## Status vocabulary (current-law handling)

| Status | Meaning |
|--------|---------|
| `current` | In force; latest revised version active |
| `amended` | In force; modified by one or more amendments |
| `repealed` | No longer in force |
| `superseded` | Replaced by a newer instrument |
| `historical` | Pre-independence or superseded; retained for context |
| `proposed` | Introduced but not enacted |
| `unknown` | Not yet verified against the authoritative source |

## Source-type vocabulary

| Type | Meaning |
|------|---------|
| `primary` | Actual legal authority (constitution, statute, regulation, official decision) |
| `secondary` | Commentary, research guides, academic materials |
| `discovery` | Library guides, indexes, search portals, directories |
| `comparative` | Materials used to compare jurisdictions |
